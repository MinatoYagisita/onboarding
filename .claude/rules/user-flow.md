# オンボーディングシステム

## 背景

* 新人教育やバイト研修などで、上司や先輩に聞くことは多いにあるが、それを画面上から質問出来るシステムがあると便利と考えた
* 社内規約、例えば有給の数を教えてなど、有給はいつ付与されるの？などのルールを社内規約からいちいち探すのがめんどくさい
* そこで、chatGPTやclaude coworkのようなわかりやすいUIから検索してAI APIが検索して結果を返却するシステムを構築する

## 概要

## ユーザー動作

### ユーザーサイド

* ユーザーはわかりやすいUIの画面から質問を自然言語で入力する
  * eneterは改行
  * command+enterで質問送付
  * プレースホルダーに「休憩は何分取れますか？」を灰色で表現する
* システムはclaude APIなどを利用して受けた質問の回答を検索する
* claude APIが検索を行うのは、管理画面から保存したその組織の資料群
  * 社内規約やマニュアルなど
  * 資料の形式は出来る限り対応する
* 受けた質問の回答を画面に表示する
* ユーザーは回答を確認する
  * 回答は以下の順序で出力する
    * 結論
    * 根拠
    * 補足
    * 注意点
    * 相談先
  * 追加で質問を受け付けることもできる
  * 回答が見つからない場合は、「回答が見つかりませんでした」などのメッセージを表示する
    * その場合は、資料が不足しているということ以外の理由はシステム上受け付けない仕組みにする
    * 関連FAQを出す
  * ユーザーの受けた質問・その際の回答は記憶し、次の精度のを上げるために利用する
    * この回答は役に立ちましたかのフィードバックを表示する
  * 回答には出典を表示する
  * 担当者に送る
    * 管理者に対して、再度質問を行う
      * 文章は同じものだと口調が異なると思うので、再入力
      * 質問をコピーするボタンを用意する
      * 送信ボタンを押す
        * 管理者へ行くので、この質問を管理者へ送付していいですか？を確認するダイアログを表示する
  * 回答をFAQ返しで終わらせず、実務で使える形に寄せる
    * 担当窓口を表示する
* 過去の質問を確認できるようにする
  * サイドバーに過去の質問の一覧を表示する
    * 過去の質問をピン留めする
    * 自分用メモを記入する
* よくある質問を表示する
  * タブを切り替える
  * 見やすいUIでよくある質問を並べる
  * よくある質問は組織ごとに決定することもできるし、実際に質問されたランキング形式でも表示する
  * カテゴリを用意する
    * カテゴリは管理者が管理する
* 認証する
  * ユーザーフロント
    * 組織の認証を設ける
    * ユーザーの認証を設ける
  * メールアドレス＋パスワードレス（メールアドレスにパスコードを送付）までを必須とする
    * オプションで生体認証（企業向け）を用意する

### 管理者サイド
* 認証する
  * 管理画面
    * 組織ごとに認証を設ける
    * バックオフィスユーザー（管理者）のユーザー認証を設ける
* 資料は管理画面からアップロードする
  * セキュリティ的に大丈夫か？
    * 自分のたちのS3（仮）のフォルダを格納するのって危険じゃない？
  * 組織が配置しているフォルダに見に行ったほうが安全か？
    * 我々も毎回見に行くので、私たちも中身は見れませんのほうがいいんじゃないか？
      * どんな方法があるか
        * お客様ごとにファイルの取得方法を変更する
          * 初期構築サポートとして、初期導入の料金を受領する
* 今利用している出典の資料を確認する
* よくある質問を設定する
* 質問されたランキングを確認する
* 自社のファイル置き場との連携を行う
  * できるだけ入力欄を少なくする
* 未回答一覧を確認する
* ユーザーの質問に対して回答が見つからなかった場合に管理者へ通知する
  * 通知方法はslackなどユーザーの使用率が高いツールを何種類か用意する
  * 管理者は通知を受けた後、本人への連絡を行う
    * ここはシステム化しない（各組織の運用に任せる）
* カテゴリを管理する
  * 例
    * 入社初日に多い質問
    * 勤怠・シフト
    * 服装・持ち物
    * 有給・休憩
    * 店舗ルール
    * トラブル時
